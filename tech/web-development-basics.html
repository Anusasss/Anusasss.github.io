Web Programavimo Pagrindai

Frontend (Vartotojo Sąsaja)

Tai, ką vartotojas mato ir su kuo sąveikauja naršyklėje.

  • HTML (HyperText Markup Language): Standartinė žymėjimo kalba, skirta kurti internetinius puslapius. Ji suteikia puslapio struktūrą ir turinį.
  • CSS (Cascading Style Sheets): Naudojama aprašyti HTML dokumento pateikimą. Ji valdo išdėstymą, spalvas, šriftus ir bendrą vizualinę išvaizdą.
  • JavaScript: Programavimo kalba, kuri leidžia kurti interaktyvius internetinius puslapius. Ji leidžia dinamiškai keisti turinį, kurti animacijas, tikrinti formas ir dar daugiau.

Backend (Serverio Dalis)

Tai, kas valdo logiką, duomenų bazes ir serverio operacijas, kurios maitina vartotojo sąsają.

  • Programavimo Kalbos: Pvz., Python, Node.js, PHP, Ruby, Java. Naudojamos rašyti serverio logiką.
  • Duomenų Bazės: Pvz., SQL, MongoDB. Naudojamos saugoti ir valdyti programos duomenis.
  • API (Application Programming Interfaces): Leidžia skirtingoms programinės įrangos sistemoms bendrauti tarpusavyje.

Kiti Svarbūs Konceptai

  • Web Serveriai: Pvz., Apache, Nginx. Programinė įranga, kuri saugo svetainės failus ir juos pateikia vartotojų naršyklėms.
  • Versijų Kontrolė: Pvz., Git/GitHub. Būtina sekti kodo pakeitimus, bendradarbiauti su kitais ir valdyti skirtingas projekto versijas.
  • Diegimas (Deployment): Procesas, kurio metu internetinė programa tampa prieinama vartotojams internete.
  • Responsinis Dizainas: Užtikrinimas, kad svetainės atrodytų ir veiktų gerai įvairiuose įrenginiuose ir ekrano dydžiuose.
