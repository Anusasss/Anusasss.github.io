# Anusasss.github.io

 Website Title: Anuso Psichologijos Refleksijos

Author: Ainius
Language: Lithuanian
Purpose: Educational and reflective platform for psychology seminar insights

Structure:
- index.html: Homepage with welcome message and site overview
- lenteles.html: Interactive tables analyzing communication elements and phenomena
- lenteles copy.html: Generic table examples for demonstration and testing
- styles.css: Dark-themed styling with gold accents for elegance and readability
- script.js: JavaScript for live search functionality across tables

Features:
- Responsive layout for desktop and mobile
- Navigation bar for easy page switching
- Searchable tables with dynamic filtering
- Semantic HTML and clean CSS structure
- Expandable for future enhancements (e.g., multimedia, user input, glossary)

Recommended Improvements:
- Add sorting and highlighting to tables
- Include multimedia content (videos, diagrams)
- Improve accessibility and mobile UX
- Introduce theme toggle and animations
- Expand content with glossary and downloadable resources

This site serves as a personal knowledge base and reflection tool for psychology studies, designed to be simple, elegant, and functional.
