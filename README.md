# Anusasss.github.io

 Website Title: Anuso Psichologijos Refleksijos

Author: Ainius
Hosted on: GitHub Pages

Purpose:
A modern, interactive, and visually elegant platform for reflecting on psychology seminar insights. Designed to be responsive, accessible, and immersive.

Structure:
- index.html: Homepage with intro, features, and navigation
- lenteles.html: Interactive analysis of communication elements and phenomena
- lenteles copy.html: Generic demo tables for testing and showcasing features
- styles.css: Fully responsive, animated, theme-aware styling with card layout
- script.js: Dynamic search, sorting, highlighting, and theme toggle logic
- readme.txt: Full documentation of site purpose, structure, and roadmap

Features:
- Responsive layout for all devices
- Sticky navigation bar with logo
- Searchable and sortable tables
- Highlighted search matches
- Theme toggle (light/dark mode)
- Card-based layout with hover effects
- Mobile-first design
- Accessible markup and semantic HTML

GitHub Pages Compatibility:
- Fully static (HTML/CSS/JS only)
- No server-side code or databases
- External libraries can be added via CDN
- Assets like images, PDFs, and fonts can be hosted

Future Ideas:
- Add glossary section
- Embed videos and diagrams
- Include downloadable resources
- Connect to external APIs for dynamic data
- Add modal popups and expandable rows

This site is a showcase of design, interactivity, and clarity — a personal knowledge base and reflection tool for psychology studies.
